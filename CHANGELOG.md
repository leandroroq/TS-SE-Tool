# Changelog

## 0.3.12.0 — Community release

- Continue maintenance as an independent community fork of LIPtoH/TS-SE-Tool.
- Include compatibility and save parsing improvements developed for ETS2 and ATS 1.61 profiles.
- Expand localization coverage and correct translated user-facing dialogs.
- Point release discovery and downloads to this repository.
- Package the application runtime assets alongside the executable.

This release is community-maintained and is not endorsed by the upstream author or SCS Software. Back up profiles and test with copied saves before editing originals.
